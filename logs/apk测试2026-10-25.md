# NotifyLedger 记账 App 第一版 · 测试日志(2026-10-25)

设备: Pixel4 模拟器(emulator-5554) / 包名 com.example.notifyledger

## 一、今天做了什么
1. **功能1 粘贴**: 把中文支付文案粘进 App, 本地规则判断, 能正确入账。修了之前 adb 传中文被截断的 bug(改成 base64 编码传, 接收端解码)。
2. **功能3 通知监听**: 今晚最大的卡点, 已修复。之前发通知一直不入账, 查 logcat 发现监听器 `onNotificationPosted` 根本没被触发。根因: targetSdk 34 需要 `POST_NOTIFICATIONS` 运行时权限, 之前 manifest 没写、也没授权, 系统静默把通知吞了(列表里查不到我们的通知 id 1001)。补上 manifest 权限 + 启动时申请 + `adb pm grant` 后, 支付通知自动入账、非支付(天气)正确丢弃。
3. **功能2 截图OCR**: 加了优雅降级(try/catch Throwable), App 不崩。
4. 重新编译 APK、装进模拟器、跑 JUnit。

## 二、结果 / 通过项
- 功能1 粘贴: 通过(账单页 ¥23.50 正确入账, 有截图 01_paste_result.png / 02_chinese_result.png)
- 功能3 通知: 通过(支付入账 + 非支付丢弃, logcat 留痕: 入口门命中 → 入账 [rule:default] 23.5 XX便利店 → 购物)

## 三、失败项 / 卡点
- 功能2 OCR: 模拟器没有 GMS 服务, ML Kit 缺类 `TextRecognizerOptionsUtils`, 真识别跑不起来, 只能降级提示"未识别到支付信息"。属环境限制, 不是代码 bug, 需真机或带 GMS 的模拟器验证。
