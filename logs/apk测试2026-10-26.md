# NotifyLedger 记账 App 第一版 · 测试日志(2026-10-26)

设备 Pixel4 模拟器(emulator-5554) / 包名 com.example.notifyledger

## 一、今天做了什么
1. **三大功能各重测 2 遍**, 截图存 verify/ (paste_r1/r2, notify_bill, ocr_bill)。
2. **修了一个质量 bug**: 通知路径的商户提取。之前发"支付宝 支付成功 ¥8.90 瑞幸咖啡 14:20 交易号2026..."时, 账本里商户显示成"(未识别商户)"、分类落到"其他"。原因是 extractMerchant 没清掉"交易号/订单号/单号"和纯数字流水、"成功"这类残留词。已加规则去残留, 现在正确提"瑞幸咖啡"、归"餐饮"。
3. 重新编译 APK + 跑 JUnit 全绿, 新包装进模拟器复验。

## 二、结果 / 通过项(大白话)
- **功能1 粘贴**: 通过。粘中文支付文案 → 点"AI 判断并记账" → 弹确认框(来源微信/金额¥23.50) → 点"入账" → 账单页出现记录。截图 paste_bill_after_entry.png。
- **功能3 通知监听**: 通过。发支付通知后, 监听器自动入账, logcat 留痕 onNotificationPosted → 入口门命中 → 入账; 非支付通知正确丢弃。截图 notify_bill_fixed.png(¥8.90 瑞幸咖啡·餐饮)。
- **功能2 截图OCR**: 优雅降级 OK。模拟器没 GMS, ML Kit 缺类会崩, 已 catch 住不崩, 界面提示"未识别到支付信息"。要真识别得用真机或带 GMS 的模拟器。
- **JUnit**: PayNotifyParserTest 24 项, 0 失败 0 错误。
- **编译**: BUILD SUCCESSFUL。
