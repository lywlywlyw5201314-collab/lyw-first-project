## 完成内容
- **账单页分类显示修正（MainActivity L317 一带）**：根因——账单行分类 chip 走英文 key 索引 `CAT_KEYS[e.category]`，而 DB 存的是中文 label（购物/其他等），索引恒 -1 → 全部误显「餐饮」。修正为 L321-322 直接 `val catLabel = e.category ?: "其他"` 并加注释。模拟器实测：盒马鲜生→购物、支付宝未识别商户→其他，不再误显餐饮。
- **parser 双端 1:1 对齐（web 为准，Kotlin 镜像）**：
  1. `parser.js` splitTransactions 段过滤 `s.match(amtRe) || /¥/`（正则字面量恒真 bug）→ `s.match(amtRe) || s.indexOf('¥') !== -1`（与 Kotlin `containsMatchIn || contains('¥')` 1:1）
  2. `parser.js` extractMerchant 末步新增空白折叠 `t.replace(/\s{2,}/g,' ')`（与 Kotlin L142 `\s{2,}` 步 1:1）
  3. `regex-align.js` L19 KT_PATH 由陈旧 `D:\apk` 修正为 `D:\apk2`（此前 9 组大差异的根因）；KNOWN_EQUIV 新增 `\r?\n` 等价条目
  4. Kotlin `PayNotifyParser.kt` 同步
- **账单页「共 N 笔」笔数元素**：`activity_main.xml` tvBillCount 默认文案 `共 0 笔`；`MainActivity.kt` L550 `tvBillCount.text = "共 $cnt 笔"`（按搜索/分类/时间筛选后计数）；tvRangeCount 与 tvBillCount 共用 `R.id.tvBillCount`（L151 有意别名，区间选择刷新同一视图，非 bug）；分析页 tvCountTotal 保持纯数字。
- **新增 drawable 10 个**：ic_cat_dining/life/other/shopping/transport、ic_tab_bill/book/rules/stats、round_bg（账单/分析页图标与圆角背景，activity_main.xml 直接引用，缺失会编译失败）。
