# NotifyLedger 记账 App 第一版 · 开发日志(2026-10-25)

## 完成内容
- **功能1 粘贴**: 修好空格编码, 中文支付文本粘贴→本地规则判断→正确入账(¥23.50 XX便利店→购物), 实测通过。
- **功能3 通知监听**: **跑通**。定位到根因: targetSdk 34 缺少运行时权限 `POST_NOTIFICATIONS`, 导致 `NotificationManagerCompat.notify()` 静默失败、通知没真正发到系统、监听器 `onNotificationPosted` 永不触发。补 manifest 权限 + 启动时申请 + `pm grant` 授权后, 支付通知自动入账(日志: 入口门命中→rule 入账 23.5 XX便利店→购物), 非支付通知(天气)正确丢弃。
- **功能2 截图 OCR**: **优雅降级但不可用**。ML Kit 中文 OCR 在模拟器缺 GMS 组件, `TextRecognition.getClient` 抛 `ClassNotFoundException: TextRecognizerOptionsUtils`, 已加 try/catch 降级(app 不崩, 界面提示"未识别到支付信息"), 但本环境下 OCR 引擎实际跑不起来。
- 编译成功(app-debug.apk), 装进 Pixel4 模拟器, 启动无崩溃。
- JUnit 测试: 之前 24 项全绿; 本次改 MainActivity 后重跑确认(结果见 junit_result.log)。

## Bug / 根因 / 方案
| 问题 | 根因 | 方案 |
|---|---|---|
| 功能3 通知不入账 | API34 缺 POST_NOTIFICATIONS 运行时权限, notify() 静默失败 | manifest 加权限 + onCreate 申请 + adb pm grant |
| 功能2 OCR 崩 | 模拟器无 GMS, ML Kit 类缺失 | try/catch(Throwable) 降级, 如实标注不可用 |
| 粘贴空格编码 | adb shell 传参截断 | 中文走 base64(text_b64) 传 ASCII, 接收端解码 |
